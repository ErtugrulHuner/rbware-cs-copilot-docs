# Weld Adjust

_Source: `RB-X_v2_1_0_User_Manual_ENG.md` (Extension Menu 5-7, Latest Update 2026/3/25)._

Weld Adjust changes wire feed speed and fine-tuning values **in real time while welding is running** — useful for dialing in the weld without stopping the program and re-editing the taught steps.

> **Kemppi-only in the current version.** Per the manual, other welder brands are not yet supported — this will be updated in a future release.

![Weld Adjust settings screen — memory address, feed speed, fine tune, robot speed](/feature-guides/weld-adjust-settings.png)

## Fields
| Field | What it does |
|---|---|
| **Memory Add.** | The welding machine memory channel number to apply the adjustment to. |
| **Feed Speed (m/min)** | Wire feed speed, adjustable within **0.5–25.0 m/min**. |
| **Fine Tune** | Fine-tunes the welding voltage within **±10.0**. |
| **Robot Speed (%)** | Changes robot travel speed by **-100% to +100%** relative to the taught speed. |

Press **OK** to apply the adjustment, or **Cancel** to discard it.
